# A friend row offers a trade and opens the friend profile from one button

## Description

On the Friends screen, a friend row's « See the profile » button opens the friend profile dialog, and a new « Propose a trade » button opens a trade draft with that friend. The friend's name becomes plain text. When either player's profile is private, the « Trades closed » line takes the trade button's place.

## Acceptance Criteria

Verify: a friend row opens the friend profile dialog from one button and a trade draft from the other; with a private profile on either side the row shows « Trades closed », with the settings link when the viewer's own profile is private.
