# The bell tells a player when others react to their feed entries, without spam

## Description

The bell gets one line per feed entry of the player that other players reacted to, raised only by a new reactor, so toggling a reaction never floods it.

## Acceptance Criteria

Verify: a second player reacting to an entry raises one line; the same player toggling the reaction off and on raises nothing new.
