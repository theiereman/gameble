# Digest: Hotwire Native, round 1 (accessed 2026-11-02)
1. iOS releases: 1.3.1 (2026-08-14 latest), 1.3.0 (2026-07-07), 1.3.0-beta (2025-09-30), 1.2.2 (2025-07-31). https://api.github.com/repos/hotwired/hotwire-native-ios/releases high.
2. Android releases: 1.3.2 (2026-10-12 latest), 1.3.1 (2026-07-27), 1.3.0 (2026-07-07), 1.2.8 (2026-05-14). https://api.github.com/repos/hotwired/hotwire-native-android/releases high.
3. 1.3.0 is breaking on both platforms (VisitProposal route handlers, HotwireNativeError, logger change): expect upgrade work (medium, summarised).
4. Repo health: iOS 311 stars, 24 open issues, last push 2026-08-27, MIT; Android 169 stars, 24 open issues, last push 2026-11-02, MIT. GitHub API, high. Backed by 37signals (Basecamp, HEY, Fizzy, ONCE), https://native.hotwired.dev/ medium.
5. Bridge components are Stimulus-based; npm package @hotwired/hotwire-native-bridge; BridgeComponent extends Stimulus Controller: fits a Stimulus-in-TypeScript app. https://native.hotwired.dev/reference/bridge-components high.
6. Store review: bare wrapper likely rejected under 4.2 (native tab bar, push, native menu recommended); one client app approved after ~3 weeks of rounds (Masilotti, 2023-08-14, medium). After 25+ apps, same author "almost never" saw rejection for web-view/HTML; rejections came from Sign in with Apple, in-app purchase, missing account deletion, onboarding, screenshots, privacy link (https://newsletter.masilotti.com/p/what-ive-learned-from-shipping-25, 2026-02-19, medium, commercial interest).
7. Auth: docs do not cover auth; practitioner pattern: long-lived signed cookie shared across web/iOS/Android + meta tag + bridge signIn/signOut (Masilotti 2025-10-23, medium). OAuth via ASWebAuthenticationSession + token handoff into OmniAuth: community gist only, low.
8. Effort: slowest projects 6-8 months when rebuilding screens natively; push, biometrics, haptics, camera, IAP mostly via bridge components; basic Xcode/Swift still needed (low-medium).
NOT FOUND: built-in bridge components list (push/haptics) and APNs/FCM registration; server-side detection (unsourced recollection: user-agent token and turbo-rails hotwire_native_app?, verify); Android Custom Tabs OAuth and cookie sharing; open-issue triage; any Hotwire-specific 4.2 rejection beyond anecdote; Capacitor comparison; solo 6-12 month reports.
