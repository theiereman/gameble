- (decision) Origin: inspired by Wikimasters (a fun Wikipedia-based card game) which is poorly built, unstable and sells in-game purchases without a legal framework; gameble = same fun, done right
- (decision) Product qualities: well-architected, holds load, pleasant and fluid UX, maintainable, open-source
- (decision) Personal goal: learning project in an unfamiliar stack (e.g. Rust) and evaluating other tech case by case (e.g. Kafka)
- (event) Web check: no public info on 'Wikimasters'; found close comparable Wikigacha (Wikipedia gacha TCG, 1 pack/min cap 10, rarity from article quality, ads); comparables captured in addendum
- (event) Inspiration confirmed: WikiMasters (wiki-masters.com), French Wikipedia card collection site with email/password login
- (decision) Motivation: ride the current TCG hype to attract real traffic, giving the user a reason to run and operate real infrastructure (user enjoys self-hosting/server ops)
- (decision) Tech principle: start simple and modular; each infra component (e.g. Kafka) is introduced only when measured load justifies it; scaling up is part of the fun
- (decision) Timeline: a playable simple-but-effective MVP within a few days
- (assumption) Few-days MVP is incompatible with the full forged scope (auctions, fees, season pass, market gating) plus learning Rust: MVP scope must be cut hard
- (decision) Learning Rust is not a goal per se; Rust considered because the project is built with AI-assisted coding and a strict compiler/type system suits that; final stack choice belongs to architecture
- (decision) MVP scope accepted: Steam login, catalog import (games >=500 reviews) with prestige rarity, 1 free booster/10 min with opening animation, collection by sets; cards store minted rarity+season from day one
- (decision) Deferred: V2 = destroy-for-credits, auction house with fees, market gating; V3 = Brotherhood Pass, seasonal recompute, Steam library badges
- (decision) i18n EN+FR shipped in MVP
- (decision) Audience: gamers, especially collectors and TCG fans
- (decision) Platforms: desktop and mobile web first; native store apps (App Store/Play Store) in a second phase
- (decision) Positioning: a 'meta-TCG' — a TCG whose cards are games, 'one TCG to rule them all'

- (decision) Store risk (third-party IP + random rewards) recorded as known risk in brief; no MVP change
- (decision) 'Meta-TCG / one TCG to rule them all' is a tagline only; no plan for non-Steam catalogs

- (decision) Pack opening: 5 cards shown face down; hovering a card shows a glow hinting its rarity; click flips it; animation intensity scales with rarity (commons fast, legendary over-the-top)
