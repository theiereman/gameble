---
idea: A new season must not leave the player with an empty collection and set progress back to zero; find another season model
goal: Make it better: reach a season rule that holds
status: complete
updated: 2026-10-14T12:19
---

- (decision) The pain is mostly lost set progress, felt as an empty collection with the total counter at 0 when a season is published
- (note) Already in AD-5: a set is identified across seasons by kind and key, which makes cross-season progress addressable
- (lock) Season = reprint (model B): a set (theme, franchise, studio, hall of fame, UFOs) is the same across seasons and a copy of a game counts for it whatever its minted season; a new season recomputes rarities and brings in games, progress carries on
- (kill) Season = expansion (model A) rejected: sets are themes and franchises, not dated expansions; one 'Roguelike' per season side by side would confuse
- (crack) With carried progress, a veteran opens a new season with sets already advanced: what is left to chase must be found
- (assumption) An economy is coming (V2 auction house, currency only from destroying cards, average sale price per card): the season model must fit it
- (lock) Each copy keeps its minted rarity and season (edition); the destruction value is fixed by that minted rarity, so a season change creates no arbitrage
- (lock) Market value is left to players: it moves with the season and their taste; the edition is shown on listings and players decide what it is worth
- (note) Open for V2 design: whether the average sale price is computed per game, per minted rarity or per edition (liquidity vs edition premium)
- (lock) What is earned stays earned: a tier reached and its reward are never lost, and they carry the mark of the season they were earned in (watermark or style)
- (lock) The set percentage is recomputed on the current season's set and may drop when the set grows; shown as new cards to find, never as a loss. A copy whose game left a set stops counting for that set only
- (lock) A tier fallen below its threshold in a new season can be earned again, with that new season's mark: re-earning each season's marks is part of what veterans chase
- (crack) Rule 'displayed tier = highest ever' conflicts with season marks: the album must show both the live tier of the current season and the marks of earlier seasons
- (lock) Season change screen, Rocket League style: at the player's first visit after a publication, a dedicated screen recaps everything they unlocked through their contributions in the season that ended (tiers with that season's mark, card backs, weekly goals) and the sets that follow them into the new one; nothing is written at publication
- (decision) A new season's mark is earned when the player meets the threshold during that season, through the usual tier check; a player already above it gets it without starting over
- (direction) The season change screen is framed in the Brotherhood's voice as its seasonal allocation (dotation saisonnière de la Confrérie)
- (decision) The Brotherhood one-line rule is too strict: the Brotherhood voice may speak at collective moments (weekly goal, seasonal allocation, and similar), at most a line per screen, never in every sentence; the rest stays plain. Amends brotherhood-tone.md beyond this idea
- (lock) The season change screen is the Brotherhood's seasonal allocation: one Brotherhood line heads it, the rest is plain copy
- (lock) The total counter counts distinct games across editions: it never falls back to 0 and never drops between seasons. The collection shows one tile per game with the best rarity owned and a badge when several editions are held; the card page lists editions owned. The rarity report counts each game in its best owned rarity
- (crack) The collection season selector ticket loses its purpose (finding old cards); at most it becomes an edition filter
- (lock) Seasons never clutter: the grid shows no season, only an edition count; the card page groups owned editions by rarity and folds them; a set shows its latest mark with a season count (Gold, 12 seasons) and the per-season detail on demand; the equipped back shows only the chosen season's mark; a chip season selector is dropped
- (note) Unanswered: whether production already has real players, which sets the migration cost of per-season tier and set rows
