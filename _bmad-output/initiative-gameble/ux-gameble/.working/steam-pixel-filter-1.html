Filtre pixel sur les visuels Steam

Les images viennent directement du CDN Steam et sont pixelisées dans le navigateur, à l'affichage. Rien n'est copié ni stocké. Chaque ligne montre le même visuel avec cinq réglages, dans un cadre provisoire à l'échelle ×4.

À regarder : à partir de quel réglage le logo du jeu devient illisible, et quel format (bandeau ou jaquette) tient le mieux.

Format A — bandeau horizontal

Image « header » de la page du store (460 × 215). Disponible pour tous les jeux.

Format B — jaquette verticale

Image de bibliothèque (600 × 900). Les jeux anciens n'en ont pas toujours : une case vide ci-dessous le signale.
