Set perso · deux éditeurs

Un set perso prend n'importe quelle carte du catalogue, possédée ou non, de 3 à 50 jeux ; un joueur en a 10 au plus, visibles par lui seul. Deux façons de le composer : A transforme la grille TOUTES LES CARTES en atelier, B ouvre le sélecteur de cartes des échanges. Dans les deux, un jeu compte une fois quelle que soit l'édition, et les cartes non possédées gardent leur face grisée et leur cadenas : on peut les ajouter, elles resteront à obtenir.

ALa grille en mode édition

Un cadre accent court sur tout le bord de l'écran tant que l'édition dure ; sous la barre du haut, la bande ÉDITION porte le nom du set (modifiable sur place) et « 12 / 50 ». Chaque carte a sa case : vide hors du set, lime cochée et cadre lime dans le set. Les filtres gagnent le groupe SET (tout, dans le set, hors du set). La barre flottante reste au-dessus de la grille. Sur le téléphone, elle remplace la barre d'onglets pour qu'on ne quitte pas l'édition par mégarde ; ici, l'enregistrement est refusé sous 3 jeux.

Comparaison

A · la grille

  • Toute la puissance de TOUTES LES CARTES (filtres, rapport, grande grille) sans rien apprendre de neuf.
  • Le mode est un état de l'écran : il faut le cadre, la bande et la barre pour qu'on sache qu'on n'est pas en train de « regarder » sa collection ; le risque est d'oublier qu'on édite.
  • Sur le téléphone, la barre d'actions prend la place des onglets pendant l'édition.

B · le sélecteur

  • Un geste déjà connu (choisir des cartes pour un échange), borné par une fenêtre : on entre, on choisit, on enregistre ou on annule.
  • Moins de place : petites cartes, filtres réduits ; pour 50 jeux, la puce SÉLECTIONNÉS devient indispensable.
  • Réutilise un composant existant ; s'ouvre aussi bien depuis « + NOUVEAU SET » que depuis « MODIFIER » dans l'album du set.
  • Refus, en ligne et en orange sous l'action qu'ils concernent : « 3 JEUX AU MOINS · Ajoutez encore 1 jeu pour enregistrer le set. » et « 50 JEUX AU PLUS · Retirez un jeu pour en ajouter un autre. ». Le bouton ENREGISTRER reste actif : c'est l'appui qui fait apparaître la raison.
  • Le nom du set : 40 caractères au plus, compteur dans le champ ; un set ne peut pas porter le nom d'un autre set du joueur.
