Tuile de set · le retournement et le chemin des paliers

Retour de recette 2026-10-27 : l'animation est trop rapide et peu belle, et les chiffres du chemin débordent du carré quand un palier demande beaucoup de cartes. Deux planches : cinq retournements à essayer au survol (le bouton rejoue sans souris), et deux chemins sans chiffre dans le nœud, montrés sur un set moyen, un très grand set et un petit set. Les cartes sont des silhouettes.

A · Le retournement

Survole une tuile, ou appuie sur « Rejouer ». A1 est l'actuel (360 ms). A2 est lent, la tuile se soulève avec une ombre. A3 attend 150 ms que l'intention soit claire, puis tourne avec un léger rebond. A4 n'a pas de rotation : le verso glisse par-dessus le recto. A5 est un fondu enchaîné avec un léger zoom, le plus calme. Le choix retenu garde le fondu pour « animations réduites ».

B · Le chemin des paliers du verso

Plus aucun nombre dans le nœud : le nombre de cartes du palier passe sous son nom, en petit. B1 garde les carrés, qui se remplissent de bas en haut selon la part du palier atteinte. B2 remplace les carrés par des cercles et fait s'illuminer la ligne en proportion des cartes du set : elle avance entre les nœuds comme une barre de chargement. Les trois cas montrent un set moyen (40/77), un très grand set (118/160, des paliers à 3 chiffres) et un petit set sans palier (3/5).
