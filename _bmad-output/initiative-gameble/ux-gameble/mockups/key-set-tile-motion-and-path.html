Tuile de set · le retournement et le chemin des paliers

Retour de recette 2026-10-27 : l'animation est trop rapide et peu belle, et les chiffres du chemin débordent du carré quand un palier demande beaucoup de cartes. Deux planches : cinq retournements à essayer au survol (le bouton rejoue sans souris), et deux chemins sans chiffre dans le nœud, montrés sur un set moyen, un très grand set et un petit set. Les cartes sont des silhouettes.

A · Le retournement, dans une liste de sets

Choisis un retournement, puis survole les tuiles de la liste (le verso reprend le chemin B2). A1 est l'actuel (360 ms). A2 est lent, la tuile se soulève avec une ombre. A3 attend 150 ms que l'intention soit claire, puis tourne avec un léger rebond. A4 n'a pas de rotation : le verso glisse par-dessus le recto. A5 est un fondu enchaîné avec un léger zoom, le plus calme. A6, le sas : la tuile s'ouvre en deux battants qui s'écartent, une ligne lumineuse sur la jonction. A7, l'écoutille : même chose à la verticale. A8, l'iris : le verso s'ouvre en cercle depuis le centre. A9, le balayage : une barre lumineuse traverse la tuile et découvre le verso. A10 : le même balayage, mais par crans de pixels. Le choix retenu garde le fondu pour « animations réduites ».

B · Le chemin des paliers du verso

Plus aucun nombre dans le nœud : le nombre de cartes qu'il faut pour atteindre le palier passe sous son nom, sans signe négatif. B1 garde les carrés, qui se remplissent de bas en haut selon la part du palier atteinte. B2 remplace les carrés par des cercles et fait s'illuminer la ligne en proportion des cartes du set : elle avance entre les nœuds comme une barre de chargement. Les trois cas montrent un set moyen (40/77), un très grand set (118/160, des paliers à 3 chiffres) et un petit set sans palier (3/5).
