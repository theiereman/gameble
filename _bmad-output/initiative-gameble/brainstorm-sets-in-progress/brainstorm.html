Technique 1 · Reverse Brainstorming

InsightThe sad version is dense identical rows, static, impersonal. Flat means no visual identity per set, no motion, no voice. The author noticed that only the set name tells one set from another, in the sad version and in the current one alike. Root cause confirmed: the current rows are as undifferentiated as the deliberately sad version.

Technique 3 · Sensory Exploration

A set is a tube of light

State is expressed by light and feel: off when empty, flickering and soft when in progress, fully lit and hard when complete. Try the push buttons.

Empty

Fully switched off. A dead object moved without effort, like a broken push button that does not spring back.
Sound: the buzz and stutter of a faulty, not quite dead neon.

In progress

A flickering, changing light and a soft, bouncy feedback.
Sound: an electrical grid gaining power as it advances.

Complete

Fully lit, hard to the touch, still.
Sound: a very steady neon hum.
InsightOff (empty), flickering and soft (in progress), fully lit and hard (complete). One thread runs through light, touch and sound.
